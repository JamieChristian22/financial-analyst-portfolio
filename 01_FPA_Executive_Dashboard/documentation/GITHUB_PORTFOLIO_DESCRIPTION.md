# GitHub Portfolio Description

**FP&A Executive Planning & Performance Model**

Corporate-style FP&A portfolio project demonstrating budget vs actual analysis, monthly P&L reporting, variance analysis, driver-based forecasting, scenario and sensitivity analysis, headcount planning, cash forecasting, DCF valuation, management commentary, reporting controls, SQL, Python, and Power BI/DAX.

Built with synthetic financial data to demonstrate an end-to-end finance workflow from raw data through executive decision support.
