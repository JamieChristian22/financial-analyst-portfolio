# Monthly FP&A Close Playbook
**Day 1:** Load actuals, completeness checks, GL/ERP tie-out, duplicate/null checks.
**Day 2:** Refresh P&L, rank variances, request commentary.
**Day 3:** Update run rate and assumptions, document changes, refresh scenarios.
**Day 4:** Draft executive commentary, assign actions, reconcile dashboard KPIs.
**Day 5:** Publish management pack, archive version, carry open actions forward.
