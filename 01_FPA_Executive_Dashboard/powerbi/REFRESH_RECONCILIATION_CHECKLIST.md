# Power BI Refresh & Reconciliation Checklist

Before publishing:
1. Refresh Financials and Date.
2. Confirm row count equals expected source count.
3. Reconcile Revenue to Excel Monthly P&L.
4. Reconcile COGS.
5. Reconcile Total OpEx.
6. Reconcile Operating Profit.
7. Validate filters do not change total logic unexpectedly.
8. Confirm materiality status logic.
9. Check Last Refresh timestamp.
10. Export executive page to PDF and spot-check visuals.

Monthly:
- Archive source file.
- Run Python validation.
- Refresh Excel model.
- Refresh Power BI.
- Complete reconciliation.
- Review commentary.
- Publish approved version.
