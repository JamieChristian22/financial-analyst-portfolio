# Analytics Architecture

## Source Layer
Synthetic order-level marketplace fact table plus seller and category dimensions.

## Transformation / QA
Python validation checks uniqueness, nulls, bounds, and revenue reconciliation.

## Analytical Layer
SQL creates executive, seller, category, refund, and trend reporting logic.

## Financial Modeling Layer
Excel converts operational metrics into marketplace P&L, unit economics, forecast, scenarios, working capital, and management commentary.

## Semantic / Visualization Layer
Power BI star-schema design, DAX measures, Date dimension, dashboard blueprint, and reconciliation checklist.

## Governance Layer
Data-quality rules, KPI definitions, exception thresholds, assumption governance, and version control.
