# Monthly Margin Review
1. Validate transaction completeness.
2. Reconcile list revenue → discounts → net revenue.
3. Reconcile material + labor + freight + overhead → COGS.
4. Review product/channel gross margins.
5. Review discount exceptions.
6. Identify price, volume, mix, and cost drivers.
7. Update price/cost assumptions.
8. Assign actions and publish reconciled executive KPIs.
