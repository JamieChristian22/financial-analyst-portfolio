# Data Dictionary

| Field | Type | Definition |
|---|---|---|
| Month | Date | First day of reporting month |
| Year | Integer | Calendar year |
| Quarter | Text | Calendar quarter |
| Business_Unit | Text | Enterprise, SMB, Digital, or Services |
| Region | Text | East, Central, or West |
| Actual_Revenue | Currency | Recorded / simulated actual revenue |
| Budget_Revenue | Currency | Approved operating-plan revenue |
| Forecast_Revenue | Currency | Latest revenue forecast |
| Actual_COGS | Currency | Actual direct cost of revenue |
| Budget_COGS | Currency | Budgeted direct cost |
| Forecast_COGS | Currency | Forecast direct cost |
| Actual_Opex | Currency | Actual operating expense |
| Budget_Opex | Currency | Budget operating expense |
| Forecast_Opex | Currency | Forecast operating expense |
| Assets | Currency | Assets assigned to operating segment |
| Operating_Cash_Flow | Currency | Cash generated from operations |
| Headcount | Integer | Segment headcount |
