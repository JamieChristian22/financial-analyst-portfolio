# Add your dashboard files here

Put your Power BI (.pbix) / Tableau (.twbx/.hyper) files in this folder.

Recommended naming:

- `Dashboard_<ProjectName>_v1.pbix`
- `Dashboard_<ProjectName>_v1.twbx`

Add exported screenshots to `../images/` using:

- `01_overview.png`
- `02_revenue_trend.png`
- `03_segment_breakdown.png`
