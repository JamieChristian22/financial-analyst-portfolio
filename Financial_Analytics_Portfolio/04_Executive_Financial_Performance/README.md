# Executive Financial Performance

**Goal:** Executive KPI scorecard (Revenue, Expenses, Net Income, Margin, ROA) with trend and drilldown.

## What’s inside
- **/data**: CSVs used for the dashboard model
- **/excel**: clickable Excel models (scenario toggles, forecasts, valuation)
- **/sql**: schema + KPI queries (joins that produce KPI tables)
- **/python**: cleaning + analysis scripts (exports charts to /outputs)
- **/outputs**: charts generated by Python (ready for README / portfolio)

## How to run (optional)
1) Open the Excel model in `/excel` and use the **Scenario** dropdown.
2) Load CSVs in `/data` into Power BI / Tableau.
3) Run SQL scripts in `/sql` (Postgres / DuckDB compatible with minor tweaks).
4) Run Python scripts:
```bash
pip install pandas matplotlib
python python/01_data_cleaning.py
python python/02_analysis_charts.py
```
