# Project Plan Template (Consulting Delivery)

## Workstreams
1) Landing Zone / Governance
2) Security Hardening
3) Architecture + Build
4) Data / Analytics (if applicable)
5) Observability + Ops Readiness
6) FinOps Optimization
7) Knowledge Transfer

## Example 30/60/90
### 0–30 Days (Stabilize + Quick Wins)
- Discovery + current-state inventory
- Well-Architected review + prioritized findings
- Enable central logging/security tooling
- Immediate cost quick wins (idle cleanup, S3 lifecycle)

### 31–60 Days (Build + Migrate)
- Implement target architecture components
- CI/CD + IaC standardization
- Migrate first workload slice / pilot

### 61–90 Days (Scale + Optimize)
- DR plan + restore drills
- Expand migration waves
- FinOps operating cadence + chargeback/showback
- Exec readout + roadmap for next quarter

## Governance
- Weekly delivery sync
- Bi-weekly architecture review
- Monthly executive readout (KPIs, cost, risks)
