# Add Your Dashboard Files — FP&A Executive Dashboard

Drop your Power BI / Tableau files here so recruiters can open them locally.

## Where to put files
- `/dashboards/` → `.pbix`, `.pbit`, `.twb`, `.twbx`
- `/images/` → exported `.png` screenshots (use 16:9 where possible)

## Naming standard
- `Dashboard_Page01_Overview.png`
- `Dashboard_Page02_Revenue.png`
- `Dashboard_Page03_Cohorts.png`

## What to screenshot (recommended)
1) Overview page
2) Trend page
3) Segmentation / Drill-down page
4) Tooltip / Details page
