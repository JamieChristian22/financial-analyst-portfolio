## 📈 Budgeting & Forecasting

**Demonstrated in:**
- `04_conversion_retention_revenue_kpis/excel/Channel_ROI_Budget_Model.xlsx`
- `01_ecommerce_funnel_optimization/excel/Ecommerce_Funnel_Model.xlsx`

**Evidence:**
- Built a **Budget vs Outcome model** where channel spend and attributed revenue can be edited to test scenarios.
- Implemented **best/base/worst-case logic** using editable assumption cells (blue input cells in Excel).
- Forecasted revenue impact using:
  - Funnel progression (Viewed → Cart → Checkout → Purchase)
  - AOV-based revenue modeling
- Created formulas such as:
  - ROI = (Revenue − Spend) / Spend
  - Revenue = Conversions × AOV
- Model dynamically updates outputs when assumptions change (true planning behavior).

**Business use case simulated:**
> A growth or finance team deciding how to allocate budget across channels to maximize ROI.
