# Job-Ready Analyst Portfolio Data Package (CSV + SQL + Python + Excel)

This zip contains **fully populated** datasets and supporting deliverables tailored to your uploaded dashboards:
- Power BI: `Amazon_Marketplace_Analytics_Dashboard.pbix`
- Power BI: `FPnA_Executive_Analytics_Dashboard.pbix`
- Tableau: `Executive Financial Performance Dashboard.twbx`
- Tableau: `Financial Analyst Portfolio Dashboard.twbx`

## Folder map
- `dashboards_original/` - copies of the uploaded dashboards
- `Amazon_Marketplace_Analytics_PowerBI/` - star schema marketplace data + KPI scripts + Excel model
- `FPnA_Executive_Analytics_PowerBI/` - FP&A actual/budget/forecast data + Excel Budget vs Actual + DCF + ROI
- `Executive_Financial_Performance_Tableau/` - financial performance dataset + ratios workbook
- `Financial_Analyst_Portfolio_Tableau/` - sales/profit dataset + discount impact workbook

## Quick start
1) Open the dashboard file you already have.
2) Replace the data source with the CSVs found in each project's `data/` folder.
3) Refresh visuals.

Each project includes:
- Clean CSVs (no missing required columns)
- SQL DDL + analysis queries
- Python scripts that output KPI tables + charts
- An Excel workbook with:
  - Financial statements style tables
  - Budget vs Actual (where relevant)
  - ROI/decision support
  - Executive-ready summary tab
